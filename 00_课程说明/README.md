# 课程文件导航与存放规则

入口见 [总导航](../README.md)。完整可见资料清单见 [文件索引.csv](文件索引.csv)。

1. 案例资料按案例存入 `01_案例研究/<案例名>/`，保留版本号。
2. 鼠王关的原始文件放入 `02_鼠王关研究/source/`；数据放入 `maps/` 或 `runs/<run_id>/`；图件放入 `outputs/<run_id>/`。
3. 每局保留原来的 `run_id`。原始 AI 与分析修改版 AI 分开存放。
4. 历史说明、试验副本与旧版输入应明确标注历史状态，不作为当前默认输入。
5. PCG 在同一仓库的 `03_PCG工程/` 开发；输入只读取 `02_鼠王关研究/` 的分类原件。
6. 每次进化实验的输出放入 `04_PCG实验输出/runs/<run_id>/`，沿用原 run ID 与内部结构；战斗/策略诊断放 `diagnostics/`，检查输出放 `checks/`，未归属 run 的日志放 `logs/`。大体积原始输出本地保留，GitHub 只跟踪索引与轻量元数据。

本次整理的逐文件移动记录、SHA-256、文本修改前备份与校验结果，见 [整理记录/2026-11-26](整理记录/2026-11-26/README.md)。


## PCG 单一来源

`03_PCG工程/` 直接读取 `02_鼠王关研究/` 的当前 graph、DXF 和地图导出。根兼容快照已停用，仅在本次 GitHub 删除前检查点中暂存；上传成功后删除，历史路径只在整理记录与历史说明中保留。

实验输出的路径迁移见 `04_PCG实验输出/迁移记录.json`，历史报告里的 `.phase14-work/<run_id>` 对应 `04_PCG实验输出/runs/<run_id>`。
