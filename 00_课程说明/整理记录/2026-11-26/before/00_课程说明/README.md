# 课程文件导航与存放规则

入口见 [总导航](../README.md)。完整可见资料清单见 [文件索引.csv](文件索引.csv)。

1. 案例资料按案例存入 `01_案例研究/<案例名>/`，保留版本号。
2. 鼠王关的原始文件放入 `02_鼠王关研究/source/`；数据放入 `maps/` 或 `runs/<run_id>/`；图件放入 `outputs/<run_id>/`。
3. 每局保留原来的 `run_id`。原始 AI 与分析修改版 AI 分开存放。
4. 历史说明、试验副本与旧版输入应明确标注历史状态，不作为当前默认输入。
5. PCG 继续在现有主工程开发，从 `03_PCG工程入口/` 进入。

本次整理的逐文件移动记录、SHA-256、文本修改前备份与校验结果，见 [整理记录/2026-11-26](整理记录/2026-11-26/README.md)。
