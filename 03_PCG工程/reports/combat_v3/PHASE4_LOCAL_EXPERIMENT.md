# Phase 4 本地单亲遗传实验验收

## 实验范围

使用 [小规模配置](../../configs/shell_single_parent_local.json)。优化种子为 177，G0 从开发 Seed 177 和 84 重建布局。每代 2 个请求，G0–G2 共 6 个请求。两组均直接用原有单亲算子、DepthmapX、Godot 和评分器，战斗值为 near_1_-1，Map Size 为 1.5，三种策略各四组扰动。Pareto 生存选择继续使用 S/F/P/D，Q 仅用于展示。

连续组用两工作进程执行到 G2。续跑组单工作进程启动，提交 G0 并退出后，由新进程从该检查点恢复，使用两工作进程完成 G1、G2。两组均为从空输出目录开始的本地实测。两组的 G0 均实际分析并执行战斗，续跑时复用本组的两份 G0 评价证书。

## 结果

| 指标 | 连续组 | G0 续跑组 |
| --- | ---: | ---: |
| 请求数／唯一已评估布局 | 6／6 | 6／6 |
| 完整草案评分 | 6 | 6 |
| 继承其他试跑的对局 | 0 | 0 |
| 新执行并认证的 Godot 对局 | 72 | 72 |
| 完成的 DepthmapX CLI 调用 | 120 | 120 |
| 续跑复用的本组评价证书 | 0 | 2 |
| 子代实际拓扑变化 | 2 | 2 |
| 记录的总进程运行时间 | 282.3 秒 | 354.2 秒 |

两份归档的三代 JSON 逐字节一致，涵盖 Genome／Layout 哈希、亲代与编辑、S/F/P/D、幸存种群及 Pareto。候选点位 CSV 逐字节匹配，72 份 Godot 对局文件的 SHA-256 匹配。G2 幸存种群为 initial-01 和 single-2-00。每组的 120 次 CLI 调用为 6 个布局 × 2 种通道状态 × 候选及参考 × 5 条 DepthmapX 命令。单次实测的运行时间受到两个试跑同期运行的影响。

命令行以两工作进程分别重建并核对两份归档，返回 complete=true、comparison.matches=true。评价证据摘要为
`fb572e24cfa1df6cc8c45148c9fda8c02c05627503994a171745763b091d664b`。

Viewer 集成测试从新归档打开 G2，读取 6 个谱系节点和当代 Pareto，并用归档真实点位绘出 Depthmap 热力图。相关 Genome、单亲算子和选择的 8 项回归测试通过。

启动和恢复进程从 PowerShell 独立启动，原启动命令返回后进程继续计算并保存结果。可复制命令见 [本地单亲遗传工程实验](../../full_pcg/README.md#本地单亲遗传工程实验)。
