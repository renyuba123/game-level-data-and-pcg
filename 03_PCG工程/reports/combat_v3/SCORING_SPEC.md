# Phase 1.3 — 可人工复算的评分协议（草案 001）

实现入口 `combat_pcg.scoring.score`，实际空间分布函数 `combat_pcg.spatial.profile/state_distances`。本阶段评分核接受已汇总的测量，不声称已完成事件采集器、战斗代理或真实 Depthmap 新协议校准。阶段 2/3 将按照以下合同实现采集器，并用原始日志重算这些输入。合成样例明确为 synthetic_test，不能作为实验成果。

## 通用规则

主分均为 0–100；最小化 [-S,-F,-P,-D]。Q=.15S+.35F+.30P+.20D，仅展示；改 Q 权重不能改变 objectives。不可行/系统错误没有 Q。旧结构损失名称独立保留。

每个 observation 必须有 value、unit、sample_count、state 和 evidence 列表。measured 必须有限且样本数>0；no_opportunities 必须 value=null、sample_count=0（该机会项质量0，原始值仍null）；未采集直接缺失并得到 UNCERTAIN，无完整主分。错误单位、NaN、无证据、混用地图或战斗配置得到 ERROR。

每个比率先逐局计算后按策略等权汇总，不能让一局频繁射击占据全部分母；三策略各四扰动。原始 numerator/denominator、逐局值和参与局 ID 由采集器一并保存。合成测试中的 sample_count 只验证合同，不声称拥有事件证据。

质量函数：增加型 q=100x；距离型 q=100 max(0,1-d/tolerance)；区间型 q=100 max(0,1-distance(x,[L,U])/tolerance)。越界不是截断成好分，而是 ERROR。表中目标都是未校准研究假设；权重来自已接受计划，非实证定律。

## S：全局50% + 功能区域50%

VGA 同一网格/状态下有 N 个有效内部点，c=Connectivity/(N-1)，m=Metric_m/sqrt(A)。A 为 floor 减静态墙/障碍后的物理地面面积，不是凸分块面积总和。Integration 保留原定义。导入方负责图纸单位到模型米转换；点位出界、负值、连通度>N-1拒绝。

对初始/全开两状态和三个指标，取 q=(5%,25%,50%,75%,95%)。固定参考尺度 a=max(q95_ref-q05_ref, .01*abs(q50_ref), 1e-9)。每项 d=mean(abs(q_candidate-q_ref))/a；global_distance 等权平均三个指标和两状态。regional_distance 对参考存在的功能类别重复同一计算，并等权平均；候选缺少参考类别罚距离1。新增类别不直接奖励。距离型 tolerance=1。

分类确定规则（优先级固定）：面积>=房间面积75分位且实际度数>=3为core；最小旋转包围矩形长宽比>=3为connector；凹度 area/convex_hull_area<.9 或含实体障碍为cover；度数1为terminal；其余side；走廊未分配点为connector。边界点按几何WKT顺序归属，不依赖ID。标签不参与。真实注册/实际图验证由上游承担。

这仍是“结构分布与功能参考的适配分”，不是完整游戏体验质量。开敞和遮挡通过视觉指标与功能分组体现，环路/战术位置还由约束、D及诊断表示；不能宣传S已经单独证明所有空间质量。该限制在Phase 3校准报告保留。

## F：获胜率50% + 反应机会25% + 补给25%

| 原始量 | 定义及数据 | 单位/范围 | 评分 |
|---|---|---|---|
| win_fraction | victory局/N；死亡和超时保留，ERROR中止评分 | fraction [0,1] | 区间[.5,.8]，容忍.5 |
| reaction_fraction | 有反应余量的威胁事件/所有已感知且可归因威胁事件。余量=预计攻击命中时间-感知时间-代理反应延迟-最短合法应对动作时长；余量>=0计合格 | fraction [0,1] | 100x |
| supply_fraction | 成功解决的资源不足事件/资源不足事件总数。资源不足=可用弹药为零且仍需输出；通过合法拾取恢复弹药为成功；死亡/超时未恢复为失败 | fraction [0,1] | 100x |

反应时间需含路径、撞墙、预警和两敌人影响，不能用隔墙欧氏距离。没有威胁/资源不足事件明确no_opportunities，不给满分。高胜率超过目标只表示难度目标适配下降，不应写成“不公平”。补给总量一致和必要供给可达属于硬检查。

## P：威胁35% + 射击窗口30% + 重获视野20% + 动作风险15%

| 原始量 | 定义及数据 | 初始目标/容忍 |
|---|---|---|
| threat_fraction | 有效威胁秒/阶段活跃秒；至少一个敌人的合法接敌+攻击时间 <= 反应+瞄准+单发时间+.5s | [.20,.55] / .25 |
| shooting_window_fraction | 有用窗口秒/阶段活跃秒；实际相机可见、枪口畅通、有弹药、足够完成瞄准+一发，并存在可完成的转移 | [.25,.65] / .25 |
| reacquisition_fraction | 丢失>=.5s后重新发现且反应余量>=0的次数/全部重新发现次数；两个敌人分别记事件 | 增加型 |
| action_risk_fraction | 处于有效威胁的换弹/拾取秒 / 换弹/拾取动作秒（并集，避免重复） | [.10,.40] / .20 |

均为[0,1] fraction；零机会显式no_opportunities；持续追逐但无射击窗口不能仅靠威胁获得优秀全分。酸液/复杂动画不进入草案。

## D：路线35% + 交战位置25% + 替代路25% + 破坏变化15%

只在成功局上评价有效战术，所有失败仍进入F和阶段证据权重。

| 原始量 | 定义及数据 | 评分 |
|---|---|---|
| route_difference | 成功轨迹在固定.5m世界网格的访问集合两两Jaccard距离均值；A△B/A∪B；至少两条胜利轨迹 | 100x |
| firing_position_diversity | 有伤害射击位置格的有效数量 exp(-sum p log p) 除以合法战斗地面格总数，p按每局伤害分布先归一再平均 | 100x |
| alternative_use | 对初始/后续实际状态中可走且有至少两条内部点不相交路径的固定采样端点对，成功轨迹实际使用至少两种路径的端点对比例 | 100x |
| destruction_use | 成功局中确实使用新开连接并改变转移/射击路线的破坏事件数/成功局已发生破坏事件总数；仅开门不使用不加分 | 100x |

端点对：按固定世界网格合法点排序，以scenario seed固定抽样，不按房间ID数；最多32对。路径以实际Portal序列及米制格轨迹共同去重。循环反复使用同一路径不增加计数。没发生破坏/替代机会不填满分。具体事件提取器在Phase 3实现并另测；本阶段不伪装已经测得这些值。

## 阶段缺失与早死

阶段1完成=到达分裂；阶段2完成=大型鼠王死亡。每局每阶段证据系数 w：完成则1；进入但未完成则min(阶段持续秒/30,1)；未到达则0。两阶段分别以全部请求局数N为分母 C_phase=sum(w)/N。30秒是待校准容忍参数，保存在配置而非隐藏常数。

除全局获胜率和S外，子分=(q_phase1*C_phase1+q_phase2*C_phase2)/2。阶段未到达显示unreached、质量0，不冒充实测；已到达但漏采集为UNCERTAIN。此系数专门避免1秒内死亡获得满压力，存在对时长的偏好，因此必须在Phase 3做敏感性检验，不能称为已证实体验标准。

N<12、胜利<2或上游UNCERTAIN时保留诊断分但状态UNCERTAIN，formal_selection_allowed=false。达到证据门槛可以显示VALID，但草案仍不允许正式选择。Wilson95仅作描述性二项区间；固定策略相关样本不是随机真人样本，不能解释为真人胜率置信区间。

## 手算例与防护

合成12局，8胜4败，全部到达第二阶段且每阶段30秒；两空间距离=.2 => S=80；机会增加型=.8、区间型处于目标区间。
F=.5*100+.25*80+.25*80=90；P=.35*100+.30*100+.20*80+.15*100=96；D=80；Q=12+31.5+28.8+16=88.3；objectives=[-80,-90,-96,-80]。

将所有局改为1秒阶段1死亡：每项阶段覆盖至多(1/30)/2，P<2，第二阶段明确未到达，状态UNCERTAIN。几何INVALID立即无Q；缺少测量不填0；NaN得到可序列化ERROR；改Q权重不改objectives。test_scoring和test_spatial逐项验证。
