# Phase 4 双亲交叉两代工程试跑

**历史版本。** 此报告记录 v2 的原始算法与结果。后续外壳进化采用 [PLANS §5.4 单亲档案方案](../../PLANS.md#54-phase-4-正式引擎与单种子验收)。

本轮在已验收的外壳布局族内执行 Generation 0–2。使用冻结在试跑配置中的 `near_1_-1` 战斗数值、`Map Size = 1.5`、三种策略和每种四个场景。Generation 0 复用首轮试跑中 8 个初始布局的已校验证据，后两代各评估 8 个遗传子代。本轮为工程试跑，正式评价请求为 0。

## 遗传、验证与筛选

1. 父代从上一代幸存种群抽取。二元锦标赛按四目标的非支配层级与拥挤度选择，第二父代必须来自不同布局。
2. 每个子代以 0.8 概率尝试交叉。当前算子在兼容的同侧角部房组之间移植角位、净尺寸和小间有无，检查供体与接收方各 1–3 个边界接口。接收方保留外壳及其边界邻接。移植后以接收方同一几何与净空规则重新建图。
3. 每个子代目标为 1–3 次局部变异。种类包含合并、拆分、隔墙移动、门洞平移、连边封闭与恢复。每次重建检查实际布局、导航、继承房组及重复布局；交叉和变异合计最多检查 8 个提案。交叉失败时记录两个尝试父代，回退后只给实际单亲画继承线。
4. 合法布局交给 DepthmapX 计算空间指标，并用 Godot 采集 12 局。父代与子代合并后按 S/F/P/D 选择并保存 Pareto、幸存种群、淘汰原因和完整操作记录。Q 用于展示。
