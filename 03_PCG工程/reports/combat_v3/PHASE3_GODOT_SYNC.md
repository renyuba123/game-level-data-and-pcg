# Phase 3 统一战斗执行

Godot 的 CombatLevel 同时服务交互场景、自动批量战斗和输入重放。它负责角色碰撞、导航、视线弹道、开枪节奏、拾取、抓取、分裂、撞门与终局。自动玩家只选择移动、朝向、开火、交互和换弹。Godot 的 Boss 使用游戏场景的追击逻辑。Python 负责布局、批次、证据与评分。Godot 批次采用游戏项目时钟，实测为 60 Hz。重放按同一整数频率计算时钟，避免将 JSON 中近似的 1/60 直接作为时间步。

## 运行

- `python -B -m combat_pcg.calibrate_shell <布局包> <输出目录> --godot <exe>` 运行完整校准。也可通过 `RATKING_GODOT_EXE` 指定执行器。
- `python -B -m combat_pcg.godot_batch <exe> <布局包> <输出目录> --capture-controls` 只运行战斗，可在 Python 中用 `godot_batch.verify_replay` 重放捕获的输入并逐帧比较。
- `calibrate_shell --legacy-proxy` 复算前期 Python 代理结果。新证据位于 Godot 子目录，批次记录布局包、GDScript、Godot 程序、项目设置、配置及每局输出的哈希。
