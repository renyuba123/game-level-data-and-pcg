# Phase 3 地图缩放与 through 交互调试

Main Inspector 的 Layout 分组新增 Map Size。默认值为 1.0，可在 0.5–3.0
范围内调节。编辑器预览和人工试玩共同缩放地板、墙体、障碍、特殊通道、
导航网格、导航连接、出生点及补给位置。玩家与敌人的碰撞尺寸、移动速度和
战斗时间保持 Inspector 中的原值，使 Map Size 可用于观察空间尺度对追逐的
影响。block 的中心位置随房间移动，半径、高度和碰撞尺寸保持原值。人工试玩
日志新增 layout_scale 字段。

Portals 分组新增 Through Interaction Range，默认 1.6 模型米。玩家进入范围
后按一次 E 即开始挤门，松开 E 后计时继续。玩家离开响应区 0.35 米以上时
取消动作。HUD 会显示可交互提示及挤门进度。自动代理读取同一响应范围。

Supplies 分组新增 Supply Pickup Seconds 与 Supply Pickup Range。默认拾取时间
为 0.4 秒，响应范围为 1.25 模型米。黄色点是弹药包。进入范围后按一次 E
即可开始拾取，松开后继续计时，离开范围才取消。HUD 显示弹药提示和进度。

Godot 4.7.2 在真实 Layout v5 包上验证 Map Size 1.5。建筑、导航使用缩放坐标，
玩家与 Boss 出生点同步移动，角色碰撞半径及 block 局部尺寸保持不变。1.75 米
响应范围内单次 E 输入可完成 0.8 秒挤门。
在 1.4 米测试范围内，单次 E 输入可完成拾取，弹药按配置增加且同一弹药包
不能重复拾取。
Boss Speed 0／4.2 的运行时速度检查继续通过。原有机制回归覆盖射击、撞门、
取弹、换弹、分裂和第二阶段击杀，issues 为空。Python 回归 62 项通过。

本次修改改变人工试玩与后续 Godot 批次的 through 交互口径。此前 Phase 3
校准记录继续作为历史证据，冻结正式协议前应使用当前提交重新运行入选配置。
Map Size 默认 1.0，正式搜索配置应显式锁定为 1.0，避免不同尺度结果混排。
