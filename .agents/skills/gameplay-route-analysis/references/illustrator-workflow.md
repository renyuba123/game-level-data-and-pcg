# Illustrator 2026 工作流

优先通过 Illustrator 原生 JSX/COM 读取 `Document.layers`、`PageItem.uuid`、路径锚点、可见性和锁定状态。PDF 兼容视图只作交叉检查，PDF paint 次序不是原生对象次序或玩家时间。原件只读；当前鼠王关只保存一份修改版 AI。

1. 读取原件与修改版哈希，盘点所有图层及重名层；用原生 UUID 或明确的退化 ID 导出 Route 和事件，不移动几何。
2. 每种图以 `*-Labels` 父层收纳自己的图形、标签、图例和事件原生图标；共用底图/墙体保持独立。不要重绘用户已有事件图标。优先沿用编辑版的 `ori_events`，Spawn 可由原件路径复制；图层移动若使 UUID 改变，按原件图层及几何中心生成对象映射审计。事件编号沿候选路线从 Spawn `001` 增至末端，End 单独标注，时间仍待录像核实。空间句法原图优先作为配色和空间位置参照；若做矢量格点，用真实 VGA 数值与已记录的色阶阈值，把格点置于该指标 `*-Labels` 子层，再叠加共用墙体。导出 SVG 时检查没有无意的嵌入截图或本机外部路径。
3. 保存修改版为 PDF-compatible AI，关闭后重新打开；按固定视图配置导出 SVG/PNG。导出清单记录源 AI 哈希、各图层组合与输出哈希。SVG 设置 `SVGFontSubsetting.GLYPHSUSED` 和 `SVGFontType.OUTLINEFONT`，避免把整套 CJK 字体嵌入每张图。不得将另行重绘的 SVG 当作 AI 导出。
4. 在缩小至 PPT 尺寸和 SVG 放大后检查墙、门、标注、事件及色标；出现遮挡、缺字、跨墙或图层缺失时修订修改版 AI 并重新导出全套。

工具脚本须幂等：已有修改版时先核对来源和版本，不从原件盲目重建；失败不清理原件或唯一可打开的修改版。所有临时副本在最终验证后清理，使本项目只剩两份 `.ai`。
